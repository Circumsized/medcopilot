# 切分要点（与代码一致）：
#   1. 章节标题按长度降序参与匹配，使"孕妇及哺乳期妇女用药"优先于"用药"；
#   2. 标题只在行首识别（^[ \t]* + MULTILINE），避免正文中的
#      "如出现不良反应请停药" 被误当作章节起点；
#   3. 首个标题前的前言保留为"概述前言"分块，不静默丢弃；
#   4. 超过 2000 字的章节按 100 字符重叠继续切分；
#   5. chunk_id 由 药名+章节+序号+正文 的 SHA-256 生成，
#      不同药品的相同文本不会冲突。
